# Workout Tracker iOS App — Спецификация

## 1. Концепция

iOS-приложение для трекинга силовых тренировок с двусторонним обменом данными через JSON:
- **Импорт плана тренировок** — пользователь получает JSON от Claude (или другого источника), вставляет в приложение, получает готовые шаблоны тренировок
- **Экспорт логов** — приложение формирует JSON с историей тренировок, пользователь отправляет Claude для анализа прогресса

## 2. MVP Scope

- Импорт JSON-плана (буфер обмена / файл), валидация по схеме
- Выбор шаблона → Active Workout
- Ввод: вес, повторы, RPE/RIR (опционально)
- Данные прошлой тренировки рядом
- Визуальная группировка: суперсеты, дроп-сеты, myo-reps, rest-pause
- Таймер отдыха (вибрация)
- Сохранение тренировки (SwiftData)
- История тренировок
- Экспорт JSON (буфер / Share Sheet)

### Вне MVP (нет PR-трекинга, графиков, HealthKit, Watch, редактора плана, кардио-блока)

## 3. Функциональные требования

### 3.1. Импорт плана
- FR-IMP-01: Импорт JSON через буфер обмена или файл
- FR-IMP-02: Валидация JSON по схеме с понятными ошибками
- FR-IMP-03: Превью плана перед подтверждением импорта
- FR-IMP-05: Поддержка нескольких импортированных планов
- FR-IMP-06: Повторный импорт с тем же plan_name предлагает обновить существующий

### 3.2. Тренировка
- FR-WRK-01: Выбор шаблона → список упражнений с подходами и заметками
- FR-WRK-02: Ввод веса (кг), повторов, RPE/RIR. Данные прошлой тренировки рядом
- FR-WRK-03: Таймер отдыха с настройкой по упражнению. Вибрация
- FR-WRK-04: Суперсеты: визуальное объединение, таймер после пары
- FR-WRK-05: Маркировка подходов: warmup, working, drop, failure
- FR-WRK-08: Добавление/удаление подходов на лету
- FR-WRK-09: Заметки к тренировке
- FR-WRK-10: Session RPE (1-10) при завершении

### 3.3. История и прогресс
- FR-HIS-01: Хронологический список тренировок с метриками

### 3.4. Экспорт
- FR-EXP-01: Экспорт логов в JSON по схеме workout-log.schema.json
- FR-EXP-02: Выбор периода экспорта
- FR-EXP-03: Копирование JSON в буфер обмена
- FR-EXP-04: Шаринг через iOS Share Sheet

## 4. Нефункциональные требования
- NFR-01: Offline-first: полная функциональность без интернета
- NFR-02: Нативный iOS (Swift/SwiftUI), iOS 17+, SwiftData
- NFR-03: Минимальный UI, большие тап-зоны, минимум навигации
- NFR-04: Данные хранятся локально
- NFR-05: JSON-экспорт до 1MB на 6 месяцев
- NFR-06: Время запуска < 1 секунда

## 5. Ключевое ограничение
- Никакого ручного создания планов в UI — только импорт JSON
- Приложение = исполнитель плана + логгер
