# IronLog — AI Gym Tracker

iOS-приложение для трекинга силовых тренировок с двусторонним обменом данными через JSON.

## Концепция

- **Импорт плана** — получаешь JSON от Claude (или другого источника), вставляешь в приложение → готовые шаблоны тренировок
- **Тренировка** — логируешь подходы, вес, повторы, RPE/RIR с таймером отдыха
- **Экспорт логов** — формируешь JSON с историей, отправляешь Claude для анализа прогресса

## Стек

- Swift / SwiftUI
- SwiftData (iOS 17+)
- MVVM + Services

## MVP Scope

- Импорт JSON-плана (буфер обмена / файл)
- Валидация по схеме
- Выбор шаблона → Active Workout
- Ввод: вес, повторы, RPE/RIR
- Визуальные группировки: суперсеты, дроп-сеты, myo-reps, rest-pause
- Таймер отдыха с вибрацией
- История тренировок
- Экспорт JSON (буфер / Share Sheet)
